## 📌 Ringkasan Proyek

Platform web ini dikembangkan sebagai media presentasi interaktif dan instrumen analisis data untuk laporan Praktik Kerja Lapangan (PKL) di **PT Madubaru (PG-PS Madukismo)**, Bantul, D.I. Yogyakarta. 

Aplikasi ini mengintegrasikan kajian **Bauran Pemasaran (Marketing Mix 7P)**, pemetaan **saluran distribusi multi-channel (247 outlet)**, kalkulasi **Nilai Tambah & Margin Metode Hayami 2 Tahap**, serta **Matriks Strategi SWOT** ke dalam antarmuka digital yang dinamis dan siap dipresentasikan pada konferensi/seminar ilmiah.

---

## 🚀 Fitur Utama

- 🎬 **Conference Mode (Presenter HUD):**
  - Tampilan layar penuh (*fullscreen*) otomatis tanpa *distraction*.
  - Navigasi slide berbasis keyboard / wireless clicker pointer (`Space`, `Arrow Keys`).
  - Stopwatch presenter terintegrasi lengkap dengan fitur **Pause / Play** (Shortcut: `P`) dan indikator peringatan durasi.
- ⚡ **Kalkulator Hayami Interaktif (Live Simulation):**
  - Fitur *1-Click Preset Switch* antara data **Tahap I (Gula Curah 50 kg)** dan **Tahap II (Gula Ritel 1 kg MK Istimewa)**.
  - Simulasi perubahan biaya, harga pasar, atau upah tenaga kerja secara *real-time* saat sesi tanya jawab (Q&A).
- 📊 **Visualisasi Data Dinamis (Chart.js):**
  - Grafik kesenjangan (*GAP*) defisit konsumsi gula nasional (BPS 2025).
  - Diagram lingkaran struktur kontribusi pendapatan 2025 (B2B vs B2C).
  - Grafik batang sebaran geografis jaringan 247 outlet ritel.
- 🎯 **Matriks Strategi SWOT:**
  - Evaluasi 4 kuadran faktor internal & eksternal serta 8 formulasi strategi taktis (SO, WO, ST, WT).

## 📈 Temuan Kunci Penelitian

| Variabel Analisis | Tahap I: Gula Curah (50 kg) | Tahap II: Gula Ritel (1 kg) |
|---|---|---|
| **Bahan Baku** | Tebu Segar (*On-farm*) | Gula Curah (*Repackaging*) |
| **Nilai Output** | Rp1.036,64 / kg tebu | Rp16.654,00 / kg gula |
| **Nilai Tambah** | **Rp266,75 / kg tebu** | **Rp1.641,00 / kg gula** |
| **Rasio Nilai Tambah** | 25,73% | 9,85% |
| **Pangsa Keuntungan Pabrik** | 86,30% (Rp230,21/kg) | 56,72% (Rp930,77/kg) |
| **Imbalan Tenaga Kerja** | 13,70% (Rp36,54/kg) | 43,28% (Rp710,23/kg) |

> **Insight Strategis:** Pengemasan ulang ke varian ritel 1 kg menghasilkan nilai tambah riil **>6 kali lipat** lebih tinggi (Rp1.641/kg) dibandingkan penjualan curah, merekomendasikan ekspansi porsi pasar B2C ritel modern oleh PT Madubaru.
